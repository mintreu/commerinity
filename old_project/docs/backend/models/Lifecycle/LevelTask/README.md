-   **Key Attributes:**

    -   `url` (string)
    -   `description` (string)
    -   `score` (integer)
    -   `min_eligible_score` (integer)
    -   `min_progress` (array)
    -   `game_type` (string)
    -   `level_id` (integer)
-   **Relationships:**

    -   `progressions()`: `hasMany` relationship to `UserLevelTaskProgress`.
-   **Traits:** `HasFactory`.
-   **Implemented Features:** Stores details about tasks that users need to complete within a level, including scoring and progress tracking.
-   **Usage:** Used to define the criteria and rewards for progressing through user levels.
