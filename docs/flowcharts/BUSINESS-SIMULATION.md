PRINCIPLE: Use SMS only when CRITICAL. Prefer in-app/push/email for others.

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│   MUST SEND VIA SMS (Critical):                                            │

│   ├── Large transaction alerts (> ₹1,000)                                  │
│   └── Security alerts (password change, new device login)                  │
│                                                                             │
│   PREFER OTHER CHANNELS:                                                   │
│   ├── Commission credited → Push notification + Email                      │
│   ├── New team member joined → Push notification                           │
│   ├── Level achievement → Push + Email                                     │
│   ├── Marketing/Promotions → Email only                                    │
│   └── Weekly summary → Email only                                          │
│                                                                             │
│   SMS COST OPTIMIZATION:                                                   │
│   ├── Batch OTPs where possible (single OTP for multiple actions)         │
│   ├── Use short templates (DLT approved)                                   │
│   ├── Cache OTPs for 5-10 mins to avoid resends                           │
│   └── Rate limit: Max 5 SMS/user/day                                       │
│                                                                             │
│   ESTIMATED SMS VOLUME (Year 1):                                           │
│   ├── OTPs: ~3,000 (1,000 users × 3 OTPs avg)                             │
