```
├── Achievable (realistic goals)
├── Fair distribution (everyone can reach Level 4)
└── Legal compliance (limited structure)
```

### Q: What's the difference between Sponsor and Originator?

<details>
<summary><b>Click to expand answer</b></summary>

```
SPONSOR vs ORIGINATOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SPONSOR (MLM Upline)
├── Relationship: Parent in genealogy tree
├── How assigned: Via referral code/link
├── Commission type: Sponsor bonus + Level commission
├── Requirement: Must be an active member
└── Purpose: MLM team building

ORIGINATOR (Business Acquisition)
├── Relationship: Who brought them to the platform
├── How assigned: Advisor/Agent who signed them up
├── Commission type: Originator joining + recurring
├── Requirement: Must have Advisor role
└── Purpose: Sales/acquisition tracking

CAN BE SAME PERSON? Yes!
If an Advisor refers someone using their link:
├── They become BOTH sponsor AND originator
├── They get BOTH types of commission
└── Double earning potential!

EXAMPLE SCENARIOS:

Scenario 1: Organic Signup
├── User finds website, registers directly
├── Sponsor: None (root user)
├── Originator: None
└── No upline commissions

Scenario 2: Referral Signup
├── User clicks member's referral link
├── Sponsor: The member who shared link
├── Originator: None
└── Sponsor gets commission

Scenario 3: Advisor Signup
├── Advisor signs up user in-person
├── Sponsor: Could be set to anyone or none
├── Originator: The Advisor
└── Advisor gets originator commission

Scenario 4: Advisor's Own Referral
├── Advisor shares their referral link
├── Sponsor: Advisor
├── Originator: Advisor
└── Advisor gets BOTH commissions!
```
