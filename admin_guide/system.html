📢 বিজ্ঞাপন ও ব্যানার (Advertisements)

ওয়েবসাইটের হোমপেজ এবং বিভিন্ন জায়গায় ব্যানার অ্যাড সেট করার নিয়ম:


Ad Placement: ব্যানারটি কোথায় দেখাবে।
Homepage Hero, Sidebar, Footer.
Link URL: ব্যান্যারে ক্লিক করলে কোন পেজে যাবে।
কেন: কোনো নির্দিষ্ট প্রোডাক্ট প্রোমোট করতে সেই প্রোডাক্টের লিংক এখানে দিন।
Image Upload: ব্যানারের ছবি।
পরামর্শ: ভালো রেজোলিউশনের ছবি ব্যবহার করুন যাতে ওয়েবসাইট প্রিমিয়াম লাগে।

✉️ এসএমএস ও নোটিফিকেশন (SMS Logs & Templates)

SMS Templates: ওটিপি (OTP) বা অর্ডার কনফার্মেশন মেসেজের ফরম্যাট।
সতর্কতা: এখানে {{ name }} বা {{ otp }} কোডগুলো পরিবর্তন করবেন না, এগুলো সিস্টেম থেকে অটো-জেনারেট হয়।
SMS Logs: কতগুলো মেসেজ পাঠানো হয়েছে এবং কতগুলো সাকসেসফুল হয়েছে।

🔧 সিস্টেম টুলস (System Tools)

Cache Manager: ওয়েবসাইটের স্পিড বাড়াতে মাঝেমধ্যে ক্যাশ ক্লিয়ার করুন।
Command Runner: এটি অ্যাডভান্সড ইউজারদের জন্য। সিস্টেম মেইনটেন্যান্স কমান্ড এখান থেকে রান করা যায়।
Activity Log: কোন অ্যাডমিন কখন কি পরিবর্তন করেছেন তার হিস্টোরি এখানে পাওয়া যাবে।
কেন: সিস্টেমের সিকিউরিটি এবং স্বচ্ছতা নিশ্চিত করার জন্য এটি জরুরি।
